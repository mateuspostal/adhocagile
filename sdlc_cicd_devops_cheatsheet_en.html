SDLC — Software Development Life Cycle
01Planning
Defines scope, schedule, resources and feasibility. Engages stakeholders and identifies risks.
Ferramentas: Jira · Confluence · MS Project
02Requirements
Collection, analysis and documentation of functional and non-functional requirements. User stories, use cases.
Ferramentas: Miro · Figma · Notion · Jira
03Design
System architecture, database design, UI/UX and API design. Fundamental technical decisions.
Ferramentas: Figma · Draw.io · Lucidchart
04Implementation (Build)
Code writing, reviews, pair programming and component integration.
Ferramentas: VS Code · Git · GitHub · GitLab
05Testing
Unit, integration, E2E, performance, security and UAT. Ensures quality before deploy.
Ferramentas: Jest · Cypress · Selenium · k6
06Deploy
Production delivery via CI/CD pipeline. Blue-green, canary or rolling deployment.
Ferramentas: GitHub Actions · ArgoCD · Helm
07Maintenance
Monitoring, bug fixing, performance improvements and user support in production.
Ferramentas: Datadog · PagerDuty · Grafana
Waterfall
Sequential and linear phases. A phase only starts when the previous one ends.
✓ Requirements fixos · projetos regulatórios
Ágil / Scrum
Iterative and incremental. Short cycles with constant customer feedback.
✓ Requirements mutáveis · produtos digitais
Spiral
Combines Waterfall and prototyping. Each cycle includes risk analysis.
✓ High-risk projects · critical systems
V-Model
Each dev phase has a corresponding test phase in a "V" shape.
✓ Embedded systems · defense · pharma

Continuous Integration (CI)
Every code change triggers the pipeline automatically
Build and tests must run in under 10 minutes
Pipeline failure blocks the merge immediately
Every commit must be integrable to the main branch

Delivery environments
💻 Development
Dev's local machine. Mock data, hot-reload, debug enabled. No SLA.
›
🔗 Integration / QA
Testing integrados e E2E. Dados sintéticos. Deploy automático a cada PR merged.
›
🎪 Staging / Pre-prod
Production mirror. Anonymized data. Manual gate before prod.
›
🚀 Production
Real users. Continuous monitoring. Active SLA. Rollback ready.
DevOps — culture, practices and tools
DevOps Pillars (CALMS)
Culture — Dev and Ops share responsibility
Automation — everything that can be automated, should be
Lean — eliminate waste in the delivery flow
Measurement — metrics guide decisions, not intuition
Sharing — feedback loops and shared knowledge
