8 Atividades principais
01
Visão do Produto
Define o propósito, problema que resolve e os benefícios esperados para o negócio.
Saída: Frase de visão validada pelo time
02
O produto É / NÃO É — FAZ / NÃO FAZ
Alinha expectativas definindo explicitamente o que está dentro e fora do escopo.
Saída: Quadrante É/NÃO É validado
03
Objetivos do Produto
Lista os objetivos de negócio que o produto deve atingir, priorizados pelo grupo.
Saída: Lista de objetivos ordenados
04
Personas
Cria perfis semifictícios dos usuários reais — necessidades, comportamentos e frustrações.
Saída: 2-4 personas documentadas
05
Jornada do Usuário
Mapeia o caminho percorrido por cada persona ao usar o produto, passo a passo.
Saída: Mapa de jornada por persona
06
Brainstorm de Features
Geração livre de funcionalidades ligadas a objetivos e personas, sem julgamento inicial.
Saída: Lista de features brutas
07
Revisão Técnica & de UX
Dev e UX avaliam cada feature: esforço (P/M/G/GG) e nível de confiança em UX.
Saída: Features com esforço e UX
08
Sequenciador & Canvas MVP
Ordena features em ondas e monta o Canvas do MVP respeitando regras de negócio.
Saída: Canvas MVP pronto para build
